AnyRouter 多账号自动签到

完全零基础用户的超详细教程 | 一键配置自动签到

这个项目是什么？

一个自动化签到工具。用它可以自动为你的多个账号每天签到，获取积分，完全无需手动操作。支持 AnyRouter、Agent Router 等多个平台。使用 GitHub Actions 自动运行，配置一次后就能自动工作。

步骤1：Fork 仓库

这一步做什么？

将官方仓库复制到你的 GitHub 账户，这样你就能配置属于你的自动签到脚本。

详细操作步骤

1
打开项目页面
  1. 打开浏览器
  2. 访问：https://github.com/loks666/anyrouter-autolog
  3. 页面加载完成
2
点击 Fork 按钮
  1. 在页面右上角找到 Fork 按钮
  2. 点击 Fork
  3. 会跳出一个对话框
Fork 按钮位置：页面右上角，在 "Watch" 按钮旁边
3
确认 Fork 创建
  1. 在弹出的对话框中，直接点 Create fork 按钮
  2. 等待 GitHub 处理（通常 1-2 秒）
  3. 页面会跳转到你的 Fork 页面
成功标志：页面标题变成 你的用户名/anyrouter-autolog
步骤1完成！仓库已 Fork 到你的账户。现在可以进行步骤2。
步骤2：获取账号信息

这一步做什么？

从浏览器中获取你的 Cookies 和 API User，这是自动签到的凭证。

重要提示：
  • Cookies 每个月失效一次，失效后会报 401 错误，需要重新获取
  • 需要手动获取 - 这是必须的手动操作步骤

详细操作步骤

1
登录目标网站
  1. 打开浏览器访问：https://anyrouter.top/
  2. 用你的账号密码登录
成功标志：页面显示你已登录
2
获取 Cookies（手动操作）
  1. 按 F12 键打开开发者工具
  2. 点击 "Application" 或 "存储" 选项卡
  3. 在左侧找到 "Cookies"
  4. 找到网站域名，展开并复制 session 值
你需要：复制 session 的值（一个很长的字符串）
步骤2完成！你现在有了 Cookies。继续步骤3。
步骤3：配置 GitHub Secret

这一步做什么？

把你的账号信息安全地存储到 GitHub，这样自动签到脚本才能使用你的账号。

工作流程

进入
Settings
→
创建
环境
→
添加
Secret
→
完成

详细操作步骤

1
进入 Settings 页面
  1. 打开你 Fork 后的仓库
  2. 点击上面的 Settings 选项卡
2
创建 Environment
  1. 在左侧菜单找到 Environments
  2. 点击 New environment
  3. 输入名称：production
  4. 点击 Configure environment
3
添加 Secret
  1. 找到 Environment secrets
  2. 点击 Add environment secret
  3. Name：ANYROUTER_ACCOUNTS
  4. Value：粘贴你的账号配置（JSON格式）
  5. 点击 Add secret
[ { "name": "我的账号", "cookies": { "session": "你的session值" } } ]
步骤3完成！账号信息已保存。
步骤4：启用 GitHub Actions

这一步做什么？

启用自动化脚本，让 GitHub 自动为你的账号签到。

详细操作步骤

1
进入 Actions 选项卡
  1. 在仓库页面，点击 Actions
2
启用 Actions
  1. 如果看到 "Actions is disabled"
  2. 点击 Enable GitHub Actions
3
启用 Workflow
  1. 找到 AnyRouter 自动签到 workflow
  2. 如果被禁用，点击 Enable workflow
步骤4完成！Workflow 已启用。

完成！你的自动签到已成功配置。
常见问题排查

问题1：看到 Error 401

原因：Cookies 过期了

解决方案：重新获取 Cookies 并更新 Secret

问题2：不确定是否成功

解决方案：手动运行 workflow 查看日志
