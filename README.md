# GitHub 项目配置指南生成 Skill

一个更加直观化的讲解Skill，可以为任何需要含手动配置环境的 GitHub 项目自动生成详细的、零基础友好的 HTML 安装指南。

## 功能特点

✨ **智能分析** - 读取 GitHub链接，自动识别配置步骤，小白友好
📖 **标准化输出** - 生成HTML 指南（项目概览 + 详细步骤 + 常见问题）  
🎨 **专业设计** - 基于柯布西耶色彩理论的极简设计  
📱 **响应式** - 完美适配手机、平板、桌面  
🧭 **快速导航** - 左侧极简导航栏，支持悬停显示和点击跳转  
🔍 **手工操作高亮** - 所有需要手动操作的地方用明黄色突出显示  
🚀 **完全自包含** - 无外部依赖，可直接浏览器打开使用  

## 使用场景

**调用这个 Skill 当：**
- 项目需要配置本地没有的软件/环境
- 项目需要多个手动操作步骤（3 步以上）
- Agent 无法完全自动化的配置流程
- 需要清晰的、零基础友好的步骤说明

**不调用的场景：**
- 项目可以直接下载、直接使用
- 所有步骤都能被 agent 自动操作

## 快速开始

**在任何agent当中使用（包括不限于Claude Code、codex、豆包、workbuddy...)**

```
帮我用这个skill安装这个项目并解释有什么用，怎么用：https://github.com/[用户]/[项目名]
```

或

```
我需要一个详细的配置步骤说明：https://github.com/[用户]/[项目名]
```

## 输出示例

Skill 会生成一个 `[项目名]-install-guide.html` 文件，包含：

### 📄完整指南结构

1. **项目概览** - 项目简介、整体工作流程、依赖关系、环境检查
2-6. **详细步骤** - 每个配置步骤的详细说明
7. **常见问题** - 最可能出现的错误和解决方案

## 配置要求
无任何额外配置需求。Skill 可直接在任何环境中使用。

## 示例生成的指南特点

- ✅ 完整的前置检查清单
- ✅ 清晰的流程图（圆形节点 + 箭头）
- ✅ 依赖关系表（标注并行步骤）
- ✅ 每步都有"是什么、为什么、怎么做、成功标志"
- ✅ 所有手工操作都用明黄色高亮
- ✅ 左侧导航栏快速跳转
- ✅ 常见错误和解决方案
- ✅ 完全自包含，离线可用

## 常见问题

**Q: 这个 Skill 能为所有 GitHub 项目生成指南吗？**  
A: 能但不需要。它只适合需要手工配置的项目。对于可以直接使用的项目，不需要这个 Skill。

**Q: 生成的 HTML 可以自定义吗？**  
A: 可以。HTML 是完全自包含的，你可以用任何文本编辑器编辑。

**Q: 可以批量生成多个项目的指南吗？**  
A: 可以。每次给一个 GitHub 链接即可，Skill 会自动生成对应的 HTML。

**Q: 生成的文件大小是多少？**  
A: 通常在 50-100KB 之间，完全可以通过邮件发送或上传。
